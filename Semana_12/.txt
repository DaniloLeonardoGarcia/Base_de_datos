SUBCONSULTAS
Las subconsultas son consultas anidadas dentro de otra consulta (SELECT, WHERE o FROM).

1. Subconsulta con IN
Se usa para verificar si un valor está dentro de un conjunto de resultados.

Ejemplo:
SELECT nombre
FROM empleados
WHERE id IN (SELECT id_empleado 
             FROM ventas 
             WHERE cantidad > 100);


2. Subconsulta con EXISTS
Se usa para verificar la existencia de filas. Es más eficiente en muchos casos con grandes volúmenes de datos.

Ejemplo:
SELECT nombre
FROM empleados e
WHERE EXISTS (SELECT 1 
              FROM ventas v 
              WHERE e.id = v.id_empleado 
                AND v.cantidad > 100);


FUNCIONES DE FECHA

• GETDATE() → Fecha y hora actual
• DAY(fecha) → Día del mes
• MONTH(fecha) → Mes
• YEAR(fecha) → Año
• DATEADD(intervalo, cantidad, fecha) → Agrega tiempo
• DATEDIFF(intervalo, fecha_inicio, fecha_fin) → Diferencia entre fechas


FUNCIONES DE CADENA

• CONCAT(cadenas) → Une cadenas
• LEN(cadena) → Longitud
• SUBSTRING(cadena, inicio, longitud) → Extrae parte
• LOWER(cadena) / UPPER(cadena) → Minúsculas / Mayúsculas
• LTRIM(cadena) / RTRIM(cadena) → Elimina espacios izquierda/derecha


FUNCIONES DE CONVERSIÓN

• CAST(expresión AS tipo) → Conversión básica
• CONVERT(tipo, expresión, [estilo]) → Conversión con formato (más flexible)

Ejemplo CONVERT:
SELECT CONVERT(VARCHAR, GETDATE(), 103) AS FechaDDMMYYYY
